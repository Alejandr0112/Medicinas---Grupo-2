# Requerimientos del Sistema

## Objetivo general

Desarrollar un sistema web para la gestión de medicinas, permitiendo registrar, consultar, actualizar y eliminar información de manera clara y ordenada.

## Requerimientos funcionales

1. El sistema debe permitir visualizar una lista de medicinas registradas.
2. El sistema debe permitir registrar nuevas medicinas.
3. El sistema debe permitir editar la información de una medicina.
4. El sistema debe permitir eliminar una medicina.
5. El sistema debe permitir buscar medicinas por nombre.
6. El sistema debe mostrar mensajes de confirmación cuando una acción se realice correctamente.
7. El sistema debe mostrar mensajes de error cuando falte información obligatoria.
8. El sistema debe permitir navegar entre las diferentes secciones mediante un menú.
9. El sistema debe contar con una pantalla principal o dashboard.
10. El sistema debe tener formularios claros para ingresar información.

## Requerimientos no funcionales

1. La interfaz debe ser fácil de usar.
2. El diseño debe ser responsive, es decir, debe adaptarse a computadora, tablet y celular.
3. Los colores deben mantenerse iguales en todo el sistema.
4. La tipografía debe ser clara y legible.
5. El sistema debe tener una estructura visual ordenada.
6. Las páginas deben cargar de forma rápida.
7. El sistema debe usar iconos para mejorar la navegación.
8. El código debe estar organizado en archivos reutilizables.

## Requerimientos de interfaz

1. El sistema debe contar con un encabezado superior.
2. El sistema debe contar con un menú lateral.
3. El sistema debe contar con un pie de página.
4. El menú lateral debe mostrar accesos a las secciones principales.
5. Los botones deben tener estilos diferenciados según su acción.
6. Los formularios deben tener campos alineados y fáciles de leer.
